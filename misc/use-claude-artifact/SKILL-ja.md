# Use Claude Artifact

ユーザーがレビュー資料・解説・デザイン確認などで HTML 出力を求めたとき、リポジトリにファイルを書かず Claude のアーティファクトとして作成する。

## 手順

1. 要求を分析する（レビュー資料 / プラン・議論の解説 / デザイン確認）
2. HTML をアーティファクトとして作成する

## Gotchas

- このスキルは HTML の置き場だけを定める。スタイルはアーティファクトのデフォルト、またはユーザー指定に従う
- ユーザーから明示されるまでリポジトリに commit しない（一時的な閲覧用であることがほとんど）
- 「HTML で作成して」でもワークスペースに `.html` を書き出さない。必ずアーティファクトとして出す
